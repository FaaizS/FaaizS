
# Hey, I'm Faaiz!

I'm a Computer Science undergraduate at the **University of Texas at Dallas**, graduating in December 2026.

My interests lie in **software engineering, backend systems, distributed computing, and applied AI/ML**. I enjoy building systems, understanding their limitations, and validating their behavior through testing, benchmarks, and experimentation.

I believe good engineering is about more than getting something to work. It's about understanding *why* it works, *where* it breaks, and *what tradeoffs were made along the way*.

## Featured Projects

- **[DiskDBLite](https://github.com/FaaizS/DiskDBLite)** — A disk-backed SQL engine built in Java with B-Tree indexing, slotted pages, and persistent storage.

- **[RaftBench](https://github.com/FaaizS/RaftBench)** — A deterministic three-node Raft consensus implementation in Go, exploring leader elections, log replication, and fault tolerance.

- **[netadmit](https://github.com/FaaizS/netadmit)** — An HTTP/1.1 server in Go exploring bounded concurrency, overload behavior, and tail latency.

- **[ChunkCheck](https://github.com/FaaizS/ChunkCheck)** — A Python retrieval benchmark evaluating how document chunking strategies affect evidence preservation, retrieval accuracy, and failure diagnosis.
